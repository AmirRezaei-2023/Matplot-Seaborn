# Matplotlib & Seaborn Tutorial 📊

A practical tutorial covering essential commands and commonly used charts in **Matplotlib** and **Seaborn**, two popular Python libraries for data visualization.

This repository provides examples to help learners understand how to create, customize, and interpret different types of plots commonly used in data analysis and exploratory data analysis (EDA).

## 🎯 Objectives

- Learn the fundamentals of Matplotlib and Seaborn
- Understand commonly used plotting functions
- Create clear and informative data visualizations
- Customize charts using titles, labels, colors, legends, and styles
- Explore relationships and distributions within datasets
- Apply visualization techniques to real-world data analysis projects

## 🛠️ Technologies & Tools

- **Python** — Programming language
- **Matplotlib** — Creating and customizing charts
- **Seaborn** — Statistical data visualization
- **NumPy** — Numerical operations
- **Pandas** — Data manipulation and analysis
- **Jupyter Notebook** — Interactive learning and experimentation

## 📈 Topics Covered

### Matplotlib
- Line plots
- Bar charts
- Scatter plots
- Histograms
- Box plots
- Pie charts
- Subplots and multiple-chart layouts
- Chart customization, labels, titles, legends, and gridlines

### Seaborn
- Scatter plots and line plots
- Histograms and distribution plots
- Box plots and violin plots
- Count plots and bar plots
- Heatmaps and correlation matrices
- Pair plots and regression plots
- Color palettes and visual styling

## 🚀 Getting Started

### Prerequisites

Install Python 3 and Jupyter Notebook, or use Google Colab.

### Installation

Install the required libraries:

```bash
pip install matplotlib seaborn pandas numpy jupyter
```

### Running the Tutorial

Clone the repository:

```bash
git clone https://github.com/YOUR_USERNAME/YOUR_REPOSITORY.git
cd YOUR_REPOSITORY
```

Start Jupyter Notebook:

```bash
jupyter notebook
```

Open the tutorial notebook and run the cells sequentially to explore the examples.

You can also upload the notebook to Google Colab and run it in your browser.
